# NasmOS

Système d'exploitation 32 bits jouet écrit purement en assembleur Nasm x86 à des fins d'apprentissage.

# Compilation

## Dépendances

Sont nécessaires pour compiler le système au format ISO :

- make 

- grub-mkrescue

- [nasm](https://www.nasm.us/)

- ld

## Compiler 

Pour générer l'ISO :

```bash
make 
```
